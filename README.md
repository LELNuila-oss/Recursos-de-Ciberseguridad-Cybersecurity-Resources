This is a personal repository where you'll find various resources to help you on your cybersecurity journey. If you're looking for something more in-depth, I recommend this repository: https://github.com/Hamed233/Cybersecurity-Mastery-Roadmap?tab=readme-ov-file

The following links are not in any particular order.

But if I had to start from scratch, I would definitely first review job postings to get an idea of ​​what companies are looking for and where there are opportunities for someone with my profile. After doing that research, I would start with Cisco; it's free and available in several languages. In parallel, I would practice on TryHackMe (I would make the effort to pay for it) and set a goal of creating two to three rooms, documenting what I did and learned on GitHub or in a Word document. Of course, the first rooms are very basic. I recommend starting by documenting important rooms, such as those for Windows in depth and how Active Directory works, since many companies use this system. I would also document Linux and Wireshark rooms. From there, I would start building a lab where I apply that knowledge, like a mini SOC Lab. It doesn't have to be perfect; it just has to be understandable to me so I can explain what's happening. At this point, I would recommend the following: https://documentation.wazuh.com/current/installation-guide/wazuh-agent/wazuh-agent-package-windows.html

Once I have the certification and an updated CV for ATS filters and other things, I'd start looking for internships or IT positions within about six months. I'd jump to a junior SOC, then I wouldn't stay in that position for more than two years. I'd look for something more managerial, like GRC, and to that end, I'd do a Flameworks implementation project, similar to ISO 27001, to be able to look for positions of that caliber. Finally, after spending five years saving for my retirement, I'd move to a country where I can build my farm and wait for...
